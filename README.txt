Aerus SDM
Super Disk Management

Unzip this folder, then double-click Install Aeru.bat for a desktop and Start Menu shortcut.
Or double-click Aerus SDM.exe and run it from this folder.

The window is the app. Drag the title to move it, and drag the edges to resize it.
The launcher icon is the inspector.

Nothing scans until you ask. The last scan is kept. Chosen folders go to the Recycle Bin unless you delete them permanently. Windows itself cannot be deleted.

Windows may show a SmartScreen warning because this copy is not signed. If you trust the download, choose More info, then Run anyway.
