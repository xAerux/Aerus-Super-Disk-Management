# Known issues and limitations

- The executable is unsigned and may produce a SmartScreen warning.
- External font resources may be unavailable offline.
- Runtime behavior depends on Windows version and test-account permissions.
- Broad clean-machine acceptance remains pending; static checks and bounded
  smoke checks do not replace physical testing.
- The application's own code is licensed under the MIT License (see LICENSE).
- No GitHub Release for v1.0.0 has been published yet, so the installer is not yet available from a release page.
- The installer is not code-signed, so Windows may show a security warning.
