# Installation

1. Download the complete repository folder.
2. Keep every file and subdirectory in its relative location.
3. Start `Aerus SDM.exe`, or run `Install Aeru.bat` to create shortcuts.
4. If SmartScreen warns because the executable is unsigned, verify the source
   and checksum before choosing whether to continue.

The package is self-contained as an Electron application. It does not bundle
AI models or require an external service for local discovery features.

Recall data is stored under the active Windows user's application-data
directory. Never copy another user's application-data directory into this
package.
