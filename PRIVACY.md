# Privacy

The distribution contains application code and neutral renderer state only.
It does not include the owner's scan results, installed-application records,
startup values, databases, logs, recovery copies, or model files.

Discovery runs locally on the tester's computer. Recall state is written to
the active user's application-data directory and is not uploaded by the
application. Do not share that directory when reporting a problem.

The release copy was checked for personal paths and credential patterns.
Generic Windows and network terms in code/assets are not user records.
